
# Personal Budget & Expense Tracker

## Project Overview

The Personal Budget & Expense Tracker is a website designed
to help users organize, record and monitor their daily expenses.

This project is part of my Web Development training.
It is developed using HTML5 and CSS3.

## Week 3 Improvements

Week 3 focuses on improving the visual design of the existing
Budget Tracker using CSS.

### 1. Intentional Color Palette

The project uses a consistent professional color scheme:

- Navy Blue (#172B4D) for headings and the header.
- Emerald Green (#16A085) for buttons and highlights.
- Light Grey (#F3F6FA) for the page background.
- White (#FFFFFF) for content cards.
- Dark Grey (#344054) for readable text.

### 2. Typography

Google Fonts are used to improve readability:

- Poppins for headings.
- Inter for body text, labels and form elements.

### 3. Expense Table Styling

The expense table includes:

- A colored header row.
- Proper cell padding.
- Borders for improved structure.
- Alternating row background colors.
- Hover effects.

### 4. Form Styling

The Add Expense form includes:

- Consistent input styling.
- Rounded input corners.
- Proper spacing.
- Focus effects.
- A professionally styled button.

### 5. CSS Box Model

The project applies:

- Margin to separate sections.
- Padding to create internal spacing.
- Borders to define content areas.
- Border-radius for rounded corners.
- Box shadows to create distinct cards.

## Project Files

### index.html
Contains the website structure, expense form, expense table,
instructions and multimedia section.

### style.css
Controls the website's colors, typography, layouts, tables,

### README.md
Provides project documentation and explains the features
and improvements made.

## How to Run the Project

1. Clone or download this repository.
2. Open the project folder.
3. Open index.html in your web browser.
4. Explore the Budget Tracker.
